# Declaración de uso de Inteligencia Artificial

## 1. IA usada

Se utilizó ChatGPT como herramienta de apoyo durante el desarrollo del mini portafolio.

## 2. Modelo

ChatGPT, modelo GPT-6.

## 3. Prompts realizados

Se realizaron consultas a ChatGPT relacionadas con:

- Identificación y corrección de errores de importación y exportación.
- Ajustes visuales en la distribución, los tamaños.
- Mejora de la estructura y organización del código para facilitar su comprensión y mantenimiento.
- Preparación de la documentación y revisión de los requisitos de entrega.

## 4. Outputs obtenidos

Se obtuvieron ejemplos de código JSX y CSS, propuestas para organizar los archivos y componentes, instrucciones para configurar las rutas, un formulario con validación, sugerencias de diseño y recomendaciones para probar y documentar el proyecto.

También se recibieron sugerencias para mejorar la apariencia visual del portafolio y organizar el código de manera más clara y estructurada.

## 5. Ajustes realizados

Las sugerencias proporcionadas por ChatGPT se incorporaron y adaptaron a la estructura del proyecto. Se realizaron ajustes visuales para aproximarse al wireframe de referencia, incluyendo distribución de los elementos, tamaños de texto.

Además, se organizó el código en componentes separados, se configuró la navegación entre las páginas y se corrigieron errores de exportación que impedían visualizar el sitio.

Los cambios se revisaron en el navegador durante el desarrollo. La versión final debe probarse para comprobar que todas las funcionalidades y los requisitos de la evaluación se cumplan.

## 6. Reflexión crítica

La inteligencia artificial fue una herramienta de apoyo para comprender la estructura de un proyecto React, organizar los componentes e identificar errores.

Su utilización no reemplaza la comprensión del código ni las pruebas del programa. Es importante revisar las sugerencias, comprobar que funcionen y ser capaz de explicar cómo se utilizan React Router, las props, el estado y la validación del formulario.

También es necesario reconocer que una respuesta de IA puede contener errores y que el resultado debe verificarse antes de entregarlo.
